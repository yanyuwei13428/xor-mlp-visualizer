05

两种框架，同一次训练

写法不同，数学一样

PyTorch · 显式循环

# 前向
hidden = torch.sigmoid(x @ W + b)
logits = hidden @ v + c
loss = F.binary_cross_entropy_with_logits(logits, target)
# 反向 + 更新
loss.backward()
optimizer.step()

TensorFlow · 同一套数学

# 前向
hidden = tf.sigmoid(tf.matmul(x, W) + b)
logits = tf.matmul(hidden, v) + c
loss = tf.reduce_mean(
  tf.nn.sigmoid_cross_entropy_with_logits(labels=target, logits=logits))
# 反向 + 更新
gradients = tape.gradient(loss, parameters)
optimizer.apply_gradients(zip(gradients, parameters))
数据来源：本地 PyTorch 2.15.0+cpu 实跑，float64，seed=7，300 轮；参数、逐轮 loss 与决策边界均由脚本计算后导出。 单文件静态页，不依赖脚本与外部资源。
